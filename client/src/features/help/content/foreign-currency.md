1. When adding the expense, enter the amount **exactly as it is on the bill**.
2. Choose the bill's **Currency** (for example USD).
3. Voyage converts it to {{baseCurrency}} using the company's current exchange rate and shows both amounts.

The rate used is saved with the bill, so the amount you are paid does not change later even if rates move.

> Note: Only currencies the company has set up appear in the list. If yours is missing, contact {{helpContact}}.
