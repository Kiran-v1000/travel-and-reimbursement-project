1. In **Finance**, select **Accounting export**.
2. Choose the date range (last month is filled in for you) and the format:
   - **CSV journal**: opens in Excel and imports into most accounting tools.
   - **Tally XML**: ready for Tally's Import Data, then Vouchers. Create the ledgers in Tally first.
3. Check the preview (how many payments and the total), then select **Export**.

Each payment is exported **only once**, so you can't book it twice. Every past export is listed underneath and can be downloaded again, identical to the first time.

> Note: Each expense category is booked to its own ledger. Administrators set the ledger names in **Administration**, under **Policy & categories**.
