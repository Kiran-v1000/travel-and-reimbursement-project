"Returned" is not a rejection. It means someone needs a small change before they can approve.

1. Open the notification, or find the request on the **Home** page under **Needs your attention**.
2. Read the yellow box at the top. It shows who returned it and why.
3. Make the change. For a trip, select **Edit**. For an expense report, edit the lines or add the missing receipt.
4. Select **Resubmit** (trips) or **Submit report** (expenses).

Earlier approvals and comments stay in the history, so nothing is lost.
