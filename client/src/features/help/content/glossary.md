| Word | What it means |
|---|---|
| Travel request | Asking permission for a business trip before you go. |
| Expense report | A list of the bills you want paid back, sent together. |
| Expense line | One bill in an expense report. |
| Cost center | The team or budget the money comes from. Usually your own team. |
| Project code | A code for client or internal projects, so costs can be charged to them. |
| Per-diem | A daily allowance, for example for meals. Current meal limit: {{mealsPerDiem}} a day. |
| Policy / policy exception | The company's travel and expense rules / going outside them, with a reason. |
| Approver | Someone who must say yes before a request moves on, such as your manager. |
| Delegation | An approver letting a colleague approve for them while they are away. |
| Returned | Sent back to you for a change. Not a rejection. |
| Finance review | Finance checking an approved expense report before paying it. |
| UTR / transaction reference | The unique number of a bank payment. It appears on your bank statement too. |
| Base currency | The currency you are paid in ({{baseCurrency}}). Foreign bills are converted into it. |
| Ledger / GL account | The accounting account an expense is booked to. Used by Finance. |
| Legal hold | A lock that keeps records safe for an audit or dispute. |
| Audit trail | The permanent record of who did what, and when. |
