## Search everything

Select the search box at the top (or press **Ctrl + K**, or **/**). Type a request code, a title, a person, a page name, or a question such as "how do I claim a taxi". Use the arrow keys and **Enter** to open a result.

## Shortcuts

| Press | To |
|---|---|
| Ctrl + K or / | Open search |
| T | Start a new travel request |
| N | Start a new expense report |
| J / K | Move down / up the approvals inbox |
| A / R / X | Approve / return / reject the selected item (approvers) |
| Esc | Close a window or panel |

> Note: Shortcuts don't fire while you are typing in a box.
